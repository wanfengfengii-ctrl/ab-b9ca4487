# 二维相位展开裁决台（TypeScript + React 纯前端）

干涉仪包裹相位只能落在一个周期内，逐点就近选周期会在二维表面留下不真实的折返。
本工具在给定**周期、圈数区间、相邻跳变上限与一个锚点**下，对逐格圈数做联立裁决：

- 每格真实相位 = 读数 + 圈数 × 周期；
- 必须满足锚点真实值与全部横纵相邻差约束；
- 裁决顺序：
  1. 所有横纵连续三格的**二阶差分绝对值之和**最小；
  2. 所有横纵**相邻差绝对值之和**最小；
  3. 行优先圈数序列**字典序**最小；
- 前两维与最优解并列时，额外给出**第二小字典序见证解**，暴露折返歧义。

## 输入规则

- 读数：2–24 行、2–4 列整数（页面编辑或粘贴导入，支持空格/Tab/逗号/分号分隔）；
- 周期：正整数；
- 全局圈数区间：连续整数，最多包含 3 个值；
- 相邻跳变上限：非负整数；
- 锚点：1 基行/列 + 该格真实相位。点击任一读数格可快速移动锚点。

非法单元、越界参数、锚点不可达、局部不可行相邻边、整体联立无解都会在结果面板定位反馈；
输入任意变化后旧结果立即撤下并重算。

## 本地开发

```bash
npm install
npm test       # vitest（求解器与穷举对拍 300+ 例、App 渲染冒烟）
npm run build  # tsc --noEmit + vite 构建
npm run dev    # 本地开发服务器
```

## Docker

静态站点（nginx，含 `/healthz` 健康检查）：

```bash
# 宿主机端口默认 8080，可用 HOST_PORT 覆盖
HOST_PORT=9000 docker compose up -d --build web
curl http://localhost:9000/healthz   # -> ok
```

一次性核验服务（单元测试 → 构建检查 → HTTP 冒烟，结束后自行退出，
退出码 0 表示全部通过）：

```bash
# --exit-code-from 透传 verify 的退出码，并在其结束后停止全部关联容器
docker compose up --build --exit-code-from verify verify
echo $?     # 0 成功；非 0 失败
```

（该命令会先按健康检查依赖自动启动 `web`，冒烟目标即 `http://web/healthz`。）

## 求解方法

列数 ≤ 4、圈数候选 ≤ 3，一行至多 3^4 = 81 种圈数组合。采用逐行轮廓 DP：
层状态为相邻两行圈数编码，转移枚举下一行；同一层同一状态的未来扩展成本完全相同，
每个状态只保留裁决键 `(o1, o2, 字典序)` 最小的一个标号。见证解由第二趟
「字典序严格大于最优序列」的双车道标号 DP 求出。最坏规模 24×4×3 圈数可即时求解。
